# Target screens

## VISEO's MVP mockups (in the docs pack)

HTML mockups of the workshop MVP in FEH's look, trimmed to what the
workshop builds. Copilot can read their exact structure, labels and
colours; each explains its behaviour in a comment at the top. Start at
index.html.

- mvp-app.html: the whole MVP as one interactive mockup (specs 001-005).
  Also online: https://aljabrialam.github.io/feh-sdd-guide/mvp/
- mvp-1-sign-in.html (spec 001)
- mvp-2-meetings.html, mvp-3-new-meeting.html (spec 002)
- mvp-4-meeting-screen.html (specs 003, 004, 005)
- mvp-5-add-action.html (spec 003)

Each static page has a PNG picture next to it. These are mockups, not the
app: the production MVP is built from them, spec by spec, in the workshop.
