Your computer

Use PowerShell for the commands below. After each install, close and reopen PowerShell so the new command is found.

Use the Terminal app for the commands below. After each install, open a new Terminal window.

The steps

1GitHub account

Create one at github.com/signup if you don't have one, and send your username to Aljabri. We use it to give you access to the workshop repo.

2Git

Run this; if Git isn't installed, macOS offers to install it (choose Install):

git --version

Install Git for Windows from git-scm.com/download/win with the default options, then check:

git --version

✓ Expected: git version 2.x (any recent version is fine)

Then tell Git who you are (use the email on your GitHub account), so your commits are labelled:

git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --global user.name
git config --global user.email

✓ Expected: your name, then your email.

3VS Code and Chrome

Install VS Code and Google Chrome if you don't already have them. VS Code is required: it's where you run the AI agent and the /speckit commands.

Turn on the code command: open VS Code, press Cmd + Shift + P, type Shell Command: Install 'code' command in PATH and press Enter. Then open a new Terminal window.

The installer adds the code command for you. Keep Add to PATH ticked, then reopen PowerShell.

code --version

✓ Expected: a version such as 1.10x.x on the first line.

Install the four extensions we use (Python, ESLint, Prettier and Playwright):

code --install-extension ms-python.python
code --install-extension dbaeumer.vscode-eslint
code --install-extension esbenp.prettier-vscode
code --install-extension ms-playwright.playwright
code --list-extensions

✓ Expected: the list includes ms-python.python, dbaeumer.vscode-eslint, esbenp.prettier-vscode and ms-playwright.playwright.

4Node.js 22 LTS · for the React frontend

Download the LTS installer (version 22 or later) from nodejs.org and run it with the default options. Then check:

node --version
node --version

✓ Expected: v22.x.x or higher. An older number such as v18 or v20 means you need to update.

5Python 3.12 or later · for the Django backend

Download from python.org/downloads and install. On the first installer screen, tick Add python.exe to PATH. Then check:

python3 --version
python --version

✓ Expected: Python 3.12.x or higher, for example Python 3.13.1.

6uv · Python tool manager

curl -LsSf https://astral.sh/uv/install.sh | sh
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

Open a new window, then check:

uv --version

✓ Expected: uv 0.x.x, any version.

7Django and Django REST Framework · the backend framework

Check that Django and Django REST Framework download and run on your laptop. This uses uv to fetch them into a temporary environment, so nothing is installed system-wide. On Day 2 the project installs its own copy with uv sync, so every pair gets the same versions.

uvx --from django django-admin --version
uvx --with djangorestframework --from django python -c "import rest_framework; print('DRF', rest_framework.VERSION)"

✓ Expected: 6.x.x (Django 5 or later is fine), then DRF 3.x.x. The first run takes a minute while it downloads.

8Spec Kit · the toolkit we use on Day 1

uv tool install specify-cli --from git+https://github.com/github/spec-kit.git
specify --version

✓ Expected: a version number. If it says "command not found", run uv tool update-shell and open a new window.

9Playwright test browser

Downloads the browser our automated tests use. Doing it now shows up any company proxy problem early.

npx playwright install chromium

✓ Expected: it finishes with no red errors. Run it a second time: it should finish in seconds, showing Chromium is already there.

10AI coding agent TBC

We're still confirming which AI coding agent the workshop will use, and we'll send install and sign-in steps as soon as it's decided. You don't need to install anything for this step yet.

Spec Kit works with several agents, so everything above stays the same whichever one we pick.

Final check: run the check script

This one command checks everything above at once. It checks the minimum versions, creates a throwaway Django + DRF project and runs Django's own manage.py check on it, and confirms the Playwright browser is downloaded. It doesn't install or change anything, and deletes its test folder when done.

Open a new terminal window, run it, and send Aljabri a screenshot of the result before Thursday 15 October.

curl -fsSL https://aljabrialam.github.io/feh-sdd-guide/check-setup.sh | bash
irm https://aljabrialam.github.io/feh-sdd-guide/check-setup.ps1 | iex

If something goes wrong

ProblemWhat to do
"command not found" or "not recognized" right after installingClose the terminal and open a new one. On Windows, if it still fails, restart the laptop.
Can't install software (no admin rights)Ask your IT team now, and tell Aljabri, so we can arrange access or a spare laptop.
Downloads time out or fail with certificate errorsA company proxy is probably blocking them. Tell Aljabri with a screenshot of the error.
Python shows an older versionOn Mac, use python3, not python. On Windows, reinstall and tick Add python.exe to PATH.
uvx fails to download DjangoYour network is blocking Python packages (PyPI). Tell Aljabri with a screenshot: the backend can't be built without it.
Windows: "running scripts is disabled on this system"Run Set-ExecutionPolicy -Scope CurrentUser RemoteSigned, answer Y, then run the check again.
Check script says FAIL for Django with "test project failed"Send Aljabri the screenshot. Downloads work, but something on the laptop stops Django from running.
code not found, but VS Code is installedMac: run Shell Command: Install 'code' command in PATH from VS Code (step 3). Windows: reinstall VS Code with Add to PATH ticked, then reopen PowerShell.
specify not found after installing Spec KitRun uv tool update-shell, then open a new terminal.
